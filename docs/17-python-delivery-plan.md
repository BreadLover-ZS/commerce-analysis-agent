## 交付范围

1. PostgreSQL 离线备份恢复：同时覆盖业务/检查点数据库和运行文件；提供可信备份的
   校验、拒绝覆盖、空目标数据库恢复和真实恢复演练。复用官方 pg_dump/pg_restore，
   不另写数据库导出格式。不备份.env或在日志/命令参数中输出数据库密码。
2. 可复现负载验收：隔离教学数据与demo模式，覆盖认证后的任务提交、执行与产物
   校验；报告并发、吞吐、P50/P95、失败及重复提交结果。没有模型或搜索费用，不用
   本机数据宣称生产容量。禁止默认连接用户当前数据库或部署地址。
3. 容器、运维和交付说明：提供可执行命令与失败处理；更新CI与项目入口，将本地
   PostgreSQL、容器CI、真实外部服务和生产公网边界分开记录。

## 约束与验收

- 所有开发演练使用临时数据库/目录，不停止或改写用户现有服务，不读取实际经营数据。
- 备份必须由操作者声明已停止API和Worker，并拒绝running/cancelling任务。声明不等于
  程序能够证明所有客户端都停止；跨数据库与文件的一致性依赖此前提。
- 备份为私有目录，包含用户、内部文档等敏感数据，不上传Git。哈希用于检测损坏，
  不提供来源认证。只恢复可信来源，dump可以包含可执行SQL。
- 恢复目标必须为新运行目录和空数据库；不使用--clean或删除既有数据库。数据库恢复
  单事务，数据库提交与文件发布不是一个事务；后半段失败必须保留可恢复文件及说明。
- 真实PG演练验证人工复核任务恢复、已有任务/PDF可读、检查点继续、权限隔离及哈希；
  非空目标、运行任务、路径越界、篡改/缺失文件和工具错误不得被静默忽略。
- 本轮不新增付费模型请求，不自动接入Tavily/RAGFlow或部署公网。域名、凭据及实际
  服务器验收需要环境条件后另行执行；保留此前同版本三个模型单例的历史证据。
